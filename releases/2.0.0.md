# Brainstorm 2.0.0

Brainstorm is now a native macOS app for exploring several image designs at once.

- Use your ChatGPT subscription through Codex, with no API key required. Your plan's usage limits apply. OpenAI and Gemini API connections remain optional, separately billed alternatives.
- Generate up to 16 variations from one brief, compare results, and refine a chosen image into a new set.
- Attach reference images by dropping, pasting, or choosing files. Sent prompts and references stay with their results; the input clears for your next message.
- Find conversations by their generated names, image previews, and iteration counts. The compose button reuses one empty draft.
- Use native macOS sidebars, toolbars, and Liquid Glass controls on supported systems.
- Check the version, build number, source revision, and build date in Settings. This release is version 2.0.0, build 3.

## Install

Download the signed, notarised DMG, open it, and drag Brainstorm into Applications. A ZIP and SHA-256 checksums are also available.

Requires an Apple Silicon Mac with macOS 14 or later. For ChatGPT subscription access, install Codex or the ChatGPT desktop app with its bundled Codex runtime, then sign in through Brainstorm's Settings. Image generation availability depends on your account and installed runtime.

Version 2 uses a new local library. The earlier Electron app's saved data remains untouched and is not automatically imported; previously exported images can be attached as references.

Hands-on testing has been on Apple Silicon with macOS 27. The automated suite also checks storage, draft reuse, provider requests, cancellation, and recovery without spending subscription allowance or API credits.
