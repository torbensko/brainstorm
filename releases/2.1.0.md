# Brainstorm 2.1.0

Brainstorm now keeps itself up to date with Sparkle.

- Automatically checks for updates and downloads them in the background. Downloaded updates install when you quit.
- Choose **Brainstorm → Check for Updates…** to check and install immediately.
- Control automatic checks and installation in Settings, alongside the current version and build details.
- Updates, release notes, and the update feed are signed. The app and installer remain signed and notarised by Apple.

## Install

Requires an Apple Silicon Mac running macOS 14 or later. Open the DMG and drag Brainstorm into **Applications**, replacing your previous copy. Version 2.0 and earlier need this one manual installation; future releases can update in place.

Your native Brainstorm conversations and images are preserved. The older Electron library remains separate and untouched. ChatGPT subscription access requires a local Codex installation and a connected ChatGPT account; plan limits apply.
